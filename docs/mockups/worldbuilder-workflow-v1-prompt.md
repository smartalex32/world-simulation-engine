## Generation prompt

Use case: ui-mockup.
Create a high-fidelity product-design concept board for "World Simulation", a desktop tool for worldbuilders. This is a proposed application interface, not a marketing landing page. The user builds a hex world, configures starting populations, simulates years forward, and investigates individual people. Base the style on a dark analytical workbench: forest-charcoal surfaces, subtly lighter panels, ivory text, restrained warm gold primary actions, muted teal selection, natural map colors. Modern readable sans-serif UI, a tasteful serif only for the world title. Refined, spacious, coherent, practical, crisp text and aligned controls. Avoid gamer HUDs, glowing neon, ornate fantasy frames, excessive microtext, source code, engine versions, hashes, technical debug information.

Composition: one large landscape concept board, ideally 3840 x 2160 resolution. A small heading at the top reads "World Simulation" and subtitle "Build a place. Seed a population. Discover its history." The board contains THREE clearly separated application views of the same fictional world. Upper left, a smaller view labeled "01  BUILD THE WORLD"; lower left, an equally sized view labeled "02  SET STARTING POPULATIONS". These two views together use about 35 percent of the board width. The remaining 65 percent is a single large hero application view labeled "03  SIMULATE & EXPLORE". The larger third view must have legible hierarchy and an expansive central hex map. Use enough margin that these are unmistakably different stages, not conflicting simultaneous editing and running controls.

First view: map editor for "The Alder Valley", large contiguous top-down HEXAGONAL tessellation (never squares), with clearly visible hex boundaries and convincing natural terrain. Show a painted forest region, hills, river, coastal water, subtle elevation contours, roads and two settlements. Map editing toolbar has short clear tool labels "Terrain", "Water", "Settlements", "Roads"; a small brush panel with forest selected, brush-size control, undo/redo, and a gold "Next: Population" button. One circle-shaped brush cursor spans several forest hexes. Actual map drawing UI, no decorative illustration pretending to be a map.

Second view: population setup for the same world. Map thumbnail with two selected settlement zones, alongside clearly labeled form fields: "Starting population" value "1,200", "Households" value "320", "Placement" value "Near settlements". A readable stacked age-distribution bar with legend "Children 30%  /  Adults 60%  /  Elders 10%". An expandable row labeled "Traits, skills & resources". Include two concise starting resource controls "Food reserves: 90 days" and "Skill profile: Agrarian". Footer action is gold "Start simulation". Keep the form prominent and obviously editable at this setup stage.

Third and largest view: a polished working simulation paused in "The Alder Valley". Header includes restrained three-stage navigation "Build  /  Populate  /  Simulate" with Simulate highlighted, and "Year 18 · Spring" with a clear "Paused" status. A compact top summary shows "Population 1,538", "Settlements 6", "Households 412". Most of the view is a gorgeous useful top-down hex map: continuous regular hex grid across land and water, river valley flowing from gray northern mountains through green forests and ochre plains toward a blue coastal bay; distinct natural landforms, understated trees and ridges inside cells, sparse settlement markers with readable names "Alderwick" and "Stoneford", a road between them. Modest map-layer chips "Terrain", "Population", "Resources". Small plus/minus map zoom and a distance scale "5 km". Highlight ONE person near Alderwick with a teal ring and a short dotted recent-movement path, visually connected to the inspector.

A right-hand inspector takes about 28 percent of that hero application's width. It shows a modest illustrated head-and-shoulders portrait of a fictional adult woman, name "Mara Fen", subtitle "27 · Farmer · Alderwick". Buttons "Follow on map" and a bookmark icon. Tabs "Overview", "Relationships", "Life history", with Overview active. Under "Right now", text "Gathering food near Alderwick". Two simple labeled bars "Health 86%" and "Energy 62%". A concise trait row "Curious · Patient · Sociable". A family section with two linked names "Tomas Fen — Partner" and "Lina Fen — Child". A small "Recent life events" list with "Year 18 · Began working new fields" and "Year 16 · Moved to Alderwick". The relationship names must remain distinct people, not abstract statistics.

At the bottom of the hero application, a clearly separate simulation control and history strip: a gold triangular play button labeled "Resume", step-forward button, controls "1 day", "1 month", "1 year", and a horizontal timeline with tick labels "Year 0", "Year 5", "Year 10", "Year 15", "Year 18". Current time cursor at Year18, a few small recorded-event markers, an understated population sparkline. Distinguish forward simulation controls from historical event markers visually. No combat controls or gamified win conditions.

Ensure all UI panels fit cleanly, have consistent spacing and borders, readable labels, ample map area, and believable product interaction states. Text should be accurate and limited to the provided essential labels. Tiny board footer: "Concept mockup · Illustrative world and people". The overall result should feel like a serious creative mapmaking and simulation tool that is approachable for a novelist or worldbuilder.
